====================================
    Test Commands Quick Reference 📝
====================================

Quick Run Tests
---------------
# Run all tests (simplest)
npm test

# Run using script (with colored output)
./run-tests.sh


Run Tests Separately
-------------------
# Run backend tests only
npm run test:backend
# Or
cd backend && npm test

# Run frontend tests only
npm run test:frontend
# Or
cd frontend && npm test


Watch Mode (for development)
----------------------------
# Backend watch mode
cd backend && npm run test:watch

# Frontend watch mode
cd frontend && npm run test:watch


View Coverage Reports
---------------------
# After running tests, open coverage report
cd backend && npm test
open coverage/lcov-report/index.html

cd frontend && npm test
open coverage/lcov-report/index.html


CI Mode (for GitHub Actions)
---------------------------
# Backend CI tests
cd backend && npm run test:ci

# Frontend CI tests
cd frontend && npm run test:ci


Run Specific Test Files
----------------------
# Backend specific tests
cd backend && npx jest src/controllers/authController.test.js

# Frontend specific tests
cd frontend && npx jest login.test.js


Debug Mode
----------
# Use Node debugger
cd backend && node --inspect-brk node_modules/.bin/jest --runInBand


Common Test Options
------------------
--watch           # Watch for file changes
--coverage        # Generate coverage report
--verbose         # Show detailed output
--silent          # Silent mode
--bail            # Stop on first failure
--runInBand       # Run serially (for debugging)
--testNamePattern # Run only matching tests


Install Dependencies
--------------------
# Install dependencies before first run
cd backend && npm install
cd frontend && npm install


Clean and Reinstall
-------------------
# Clean node_modules and reinstall
cd backend && rm -rf node_modules && npm install
cd frontend && rm -rf node_modules && npm install


Check Test Files
----------------
# List all test files
find . -name "*.test.js" -o -name "*.spec.js" | grep -v node_modules

# Count test files
find . -name "*.test.js" -not -path "*/node_modules/*" | wc -l


Verify Configuration
--------------------
# Verify Jest configuration
cd backend && npx jest --showConfig
cd frontend && npx jest --showConfig


Troubleshooting
---------------
Issue: Module not found error
Solution: npm install

Issue: Test timeout
Solution: Increase testTimeout in jest.config.js

Issue: Coverage threshold not met
Solution: Add more tests or lower coverageThreshold

Issue: Tests stuck/hanging
Solution: Use --runInBand option
