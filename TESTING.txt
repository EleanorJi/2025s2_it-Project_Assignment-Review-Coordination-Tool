📦 How to Run Tests
-------------------
# Run all tests
npm test

# Run backend tests only
npm run test:backend

# Run frontend tests only
npm run test:frontend

# Run using script
./run-tests.sh

# Run in respective directories
cd backend && npm test
cd frontend && npm test
