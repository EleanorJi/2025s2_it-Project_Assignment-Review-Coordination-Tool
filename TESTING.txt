📦 如何运行测试
---------------
# 运行所有测试
npm test

# 只运行后端测试
npm run test:backend

# 只运行前端测试
npm run test:frontend

# 使用脚本运行
./run-tests.sh

# 在各自目录中运行
cd backend && npm test
cd frontend && npm test

🎯 在GitHub上查看
