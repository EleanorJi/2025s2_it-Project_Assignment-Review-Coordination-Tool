🎯 如何在GitHub上看到绿色测试勾勾
----------------------------------

第一步：推送代码到GitHub
-----------------------
1. 在GitHub上创建一个新仓库（如果还没有）

2. 在项目根目录执行：
   git init
   git add .
   git commit -m "Add Jest testing with GitHub Actions CI"
   git remote add origin https://github.com/你的用户名/你的仓库名.git
   git push -u origin main

第二步：查看GitHub Actions运行
-----------------------------
1. 推送后，打开你的GitHub仓库页面
2. 点击顶部的 "Actions" 标签
3. 你会看到：
   ✅ CI Tests workflow 正在运行或已完成
   ✅ Backend Tests (Node 18.x, 20.x)
   ✅ Frontend Tests (Node 18.x, 20.x)
   ✅ Code Quality Check
   ✅ Test Summary

第三步：查看测试详情
-------------------
点击任何一个workflow运行：
- 绿色勾勾 ✅ = 所有测试通过
- 红色叉叉 ❌ = 有测试失败
- 黄色点 🟡 = 测试正在运行

展开每个job可以看到详细的测试输出：
- 30个后端测试全部通过
- 67个前端测试全部通过
- 总共97个测试用例

第四步：添加状态徽章到README
---------------------------
在你的README.md中添加以下代码：

![CI Tests](https://github.com/你的用户名/你的仓库名/workflows/CI%20Tests/badge.svg)

这会显示一个漂亮的徽章：
✅ passing (绿色) = 所有测试通过
❌ failing (红色) = 有测试失败

🔧 如果测试失败怎么办
--------------------
1. 点击失败的job查看详细日志
2. 找到失败的测试用例
3. 在本地运行测试调试：
   cd backend && npm test
   或
   cd frontend && npm test
4. 修复后重新提交：
   git add .
   git commit -m "Fix failing tests"
   git push

🎨 自定义配置
-----------
你可以编辑 .github/workflows/ci.yml 来：
- 更改触发条件（不同的分支）
- 添加更多Node.js版本
- 添加代码检查工具（ESLint, Prettier）
- 配置自动部署

💡 专业提示
----------
1. 每次提交前在本地运行测试
2. 使用 git hooks 自动运行测试
3. 保持测试简洁和快速
4. 定期更新测试用例
5. 维护高测试覆盖率
